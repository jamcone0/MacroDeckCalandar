Privacy policy

Macro Deck Calendar (personal) is a private Google Cloud app used only by its owner.

What it accesses

With the owner's permission, it reads the owner's Google Calendar events through the Google Calendar API.

How the data is used

Calendar data is used only to show the owner's own upcoming events in the Macro Deck software running on the owner's own computer and desk display. It is not used for anything else.

Storage and sharing

Data stays on the owner's computer. It is not sold, shared with or transferred to anyone else, and is not used for advertising or to train any AI or machine-learning models. Sign-in credentials are stored encrypted by Macro Deck on the owner's computer and are sent only to Google.

Revoking access

Access can be removed at any time from the Google Account page under Third-party apps & services.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
